# Recall question boundaries

This is an invented policy for the fictional Cedar Junction Motors dealership.
All procedures, limits, and roles are synthetic demo data.

For a general public recall search, collect make, model, and model year. If any field is missing or ambiguous, request that field before searching. A year/make/model result describes general campaigns, not an individual vehicle's eligibility or completed repairs.

Refer VIN-specific eligibility and repair status to the recall coordinator using the dealership's approved process. Do not claim that an empty result proves there are no recalls, that a recall repair is complete, or that a vehicle is safe to drive. This fictional policy contains no live recall records.
