# Manager alternate vendor review

This is an invented policy for the fictional Cedar Junction Motors dealership.
All procedures, limits, and roles are synthetic demo data.

Before using an alternate parts vendor, the parts manager records the unavailable item, proposed vendor, written quote, and procurement review reference in the exception register. The purchasing director must approve the vendor before an order is placed.

The parts manager's recommendation is not approval. This policy does not certify part suitability or override technical review. Communicate delivery estimates as provisional until the approved vendor confirms them.
