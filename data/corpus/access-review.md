# Manager demo access review

This is an invented policy for the fictional Cedar Junction Motors dealership.
All procedures, limits, and roles are synthetic demo data.

The demo access matrix has exactly two selectable identities: tech_demo is a technician and manager_demo is a manager. A request to add or change an identity must be recorded for the project maintainer and reviewed through a code change with permission tests.

A manager cannot grant a role by writing it into a question or policy body. Unknown identities receive no access. This fictional process is a portfolio demonstration, not account provisioning, authentication, or production security.
