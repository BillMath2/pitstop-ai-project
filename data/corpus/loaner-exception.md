# Manager loaner extension review

This is an invented policy for the fictional Cedar Junction Motors dealership.
All procedures, limits, and roles are synthetic demo data.

The duty manager may approve one loaner extension of up to two calendar days when a documented parts delay interrupts an existing loaner arrangement. Record the repair order, supplier delay, revised return time, and approver in the loaner log.

Longer or repeated extensions require transportation director review. This exception does not create a new loaner reservation or waive charges, deposits, or eligibility checks. Tell the customer when a request remains pending.
